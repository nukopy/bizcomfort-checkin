# 実装中に残した問題

2026-10-26。テストは通している。ここに書いた箇所は、実ページを取り切れていないための仮の判定である。

## 解除の成功と失敗の見た目

ログイン後の解除ページの HTML は取得していない。成功は、ページ本文に「拠点」または「ドア」があること。先にエラー欄が見つかったときは失敗にする。

エラー欄として探すのは `alert-danger`、`errorlist`、`role="alert"` だけ。サイトが別の印を使っていると文は取れない。そのときはポップアップを「解除に失敗しました」だけにする。

## 退室 URL

退室の URL 自体には、未ログインの GET をしていない。入室と同じく `/login?next=` へ移る前提で同じ手順にしている。

## 市区町村の文字列

逆ジオコードは OS のジオコーダに `ja_JP` を渡す。返る行政名が「東京都大田区」と完全に一致する保証はない。空ならログの市区町村は `FAILED` にする。
